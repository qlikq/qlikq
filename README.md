## Featured open-source project

### [xDPsApiExplorer](https://github.com/qlikq/xDPsApiExplorer)

An offline API and object-graph explorer for **PowerShell, VMware PowerCLI, and the vSphere Web Services SDK**.

- Explore live objects alongside their .NET type structure.
- Navigate relationships through an interactive, self-contained HTML graph.
- Build PowerShell filters and generate `Get-View` helpers.
- Browse embedded vSphere SDK documentation without external CDNs.

```powershell
Install-Module -Name xDPsApiExplorer -Scope CurrentUser
Import-Module xDPsApiExplorer

Get-Process -Id $PID | Show-ApiContext -MaxDepth 3
```
